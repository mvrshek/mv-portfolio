# Civic progress challenge images

Place your images in this folder:

- `hero.jpg`: wide image at the top of the project page (16:9 recommended).
- `detail.jpg`: image beside the project details text farther down the page.

The page shows placeholders until images are added. Use these exact filenames,
or update the image paths in `app/projects/civic-progress-challenge/page.tsx`.

Edit the overview and project details text in that page, and the card description
in `components/Projects.tsx`.
